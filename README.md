# homebrew-manygit

Homebrew tap for [manygit](https://github.com/rabeeh-ta/manygit) — a lazygit-style
terminal UI for a whole tree of git repos.

## Install

```bash
brew tap rabeeh-ta/manygit
brew trust rabeeh-ta/manygit
brew install manygit
```

### Why the `trust` step?

Since Homebrew 6.0.0, Homebrew does not load formulae or casks from a third-party
tap until you trust it — loading one runs Ruby from the tap, so it is an explicit
opt-in. Every non-official tap works this way; see
[Tap Trust](https://docs.brew.sh/Tap-Trust).

`brew trust rabeeh-ta/manygit` trusts this tap's current and future contents. To
trust only manygit, use `brew trust --cask rabeeh-ta/manygit/manygit` instead.

## Notes

- **macOS only.** Homebrew casks are not supported on Homebrew for Linux. On Linux,
  install manygit with the script: `curl -fsSL https://raw.githubusercontent.com/rabeeh-ta/manygit/main/install.sh | bash`
- **Homebrew owns the binary**, so manygit never replaces itself here. It reports a
  new release at most once a day and leaves `brew upgrade manygit` to you.
- `Casks/manygit.rb` is **generated by GoReleaser** on every tagged release of the
  main repo. Do not edit it by hand — changes are overwritten on the next release.
